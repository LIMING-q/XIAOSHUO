# 墨泉 · AI 小说生成器 v2.0

> 🎉 **v2.0.0 正式发布** — 2026-08-28
> 📋 [变更日志](CHANGELOG.md) · 🚀 [发布说明](RELEASE.md) · 🧪 [测试覆盖率](TEST_COVERAGE.md)

一个纯前端、零依赖的小说创作工具：从一句话设定开始，自动生成完整大纲、角色卡与正文，支持本地智能引擎与 AI 大模型双引擎。

> 双击 `index.html` 即可使用，无需安装、无需联网（本地引擎模式）。所有数据保存在浏览器本地（localStorage），不上传任何服务器。

---

## ✨ 功能一览

| 模块 | 能力 |

| **🏙️ 地点百科** | 创作时维护自定义地点池（名称/描述/出场章节/关联角色），**本地引擎生成正文与大纲时优先从中选取场景**；**章节生成后自动追踪**——地点名匹配成功时自动写入出场章节和关联角色，不再手动维护 |
| **性格化对话** | 对话自动套用角色性格台词风格——沉默寡言、锋芒毕露、温和宽厚……同一场景中性格不同的角色，语气与用词明显区分 |
| **🔗 角色关系图** | 在角色页一键切换为关系图视图——可拖拽节点重新布局，连线显示角色关系（盟友/宿敌/师徒/同门/情侣/血亲），点连线或「＋ 添加关系」编辑，**角色生成时自动补全默认关系边** |

| **重写本章** | 一键用另一种文风（古风 / 热血 / 悬疑 / 文艺 / 诙谐 / 史诗）重写当前章，重写稿先在下方预览区展开，满意后进入「原稿 / 重写版」对比模式再决定是否采用，可随时放弃 |
| **AI 深度创作** | 配置 AI 接口后，大纲、角色、正文、重写全部可走 AI 生成；每个模块可在「本地模板 / AI 深度」间自由切换；**🤖 AI 审稿助手**：生成/重写完成后可让 AI 审阅本章，给出节奏分析、对话点评（含 OOC 检测）、伏笔状态、可删减段落与总评；**🧪 AI 设定一致性检查**：大纲页一键让 AI 通读全书，报告时间线 / 人物行为 / 设定冲突 / 情节遗漏四类矛盾（按严重度排序，附修改建议） |

## 🚀 快速开始

1. 打开 `index.html`（推荐 Chrome / Edge）。
2. 点「＋ 创作新小说」：选题材（11 种）、文风（6 内置 + 自定义）、**叙事模板**（三幕 / 英雄之旅 / 七点式 / 救猫咪）、章节数（5–9999），填书名与主角（可留空自动生成），或直接点「🎲 一键随机设定」再微调。点「开始创作」。
3. 想用 AI 深度创作？右上角「🤖 AI 设置」填入 Base URL / API Key / 模型名（详见下文「配置 AI 服务商」），点「测试连接」验证。
4. 按「大纲 → 角色 → 地点 → 写作台」推进创作（详见「使用指南」）。

## 📖 使用指南

「开始创作」后进入工作台，四个标签页 + 写作台构成完整创作流程：
   - **大纲页**：查看三幕章节结构，可逐章编辑、重新生成。工具栏「🔮 伏笔追踪」展开追踪面板：每条伏笔标注埋设章 → 回收章与状态（✅ 已回收 = 回收章已写正文；⏳ 待回收 = 回收章未写；⚠️ 悬空 = 章节被删或拖拽打乱了顺序），可按全部 / 已回收 / 待回收筛选，点章节名直达该章；「＋ 手动埋设」可自己埋一条（选埋设章 / 回收章 / 写描述）。重新生成大纲时引擎自动埋设 2 条并重建追踪表，手动条目保留；拖拽排序后埋设 / 回收索引自动跟随位移。
   - **角色页**：查看自动生成的角色卡。点「🔗 关系图」切换到可视化关系图——拖拽节点自由布局，连线标注关系类型，点连线编辑、空白处添加新关系。
   - **地点页**：维护自定义地点池——加名字、写描述；本地引擎生成正文和大纲时优先从你的地点池中选取场景。
   - **写作台**：点「生成本章」生成正文，点「✎ 重写本章」换文风重写并对比。手写 / 生成的内容每 5 秒自动保存为草稿（关页、刷新、切后台时也会立即保存）；若刷新后发现正文丢失，写作台顶部会出现「📝 检测到未保存的草稿」恢复条，可一键恢复或丢弃。
   - **重写也走下方预览**：点「✎ 重写本章」后，重写稿先在下方针预览区逐段展开（实时耗时、可取消）——原稿保持不动；完成后点「✓ 进入对比模式」才进入「原稿 / 重写版」双栏对比条（编辑锁定、可来回切换），或「✕ 放弃」保持原文；取消 / 失败时原稿始终不被改动。
   - **🤖 AI 审稿**（需配置 AI）：生成本章或重写完成后，预览区底部出现「🤖 AI 审稿」按钮——点击后 AI 通读全章，分四个维度给出报告：🎵 节奏分析、💬 对话点评（检测 OOC 台词）、🔮 伏笔状态（已满足/未回收/可增设）、✂️ 可删减段落（引用原文短句+理由），附 📝 一句话总评。审稿时上方有加载提示和耗时统计。
   - **🧪 AI 设定一致性检查**（需配置 AI）：大纲页工具栏点「🧪 AI 一致性」——AI 通读全书（角色设定 + 全部章节摘要与正文节选，长书自动截断控制上下文），检查四类矛盾：⏱ 时间线错乱、👤 人物行为不符（含已死角色复现）、🏷 设定冲突（地名/称呼/能力前后不一）、🧩 情节遗漏（伏笔没收/约定遗忘）。报告按严重度（高/中/低）排序，每条标注章节、矛盾描述与修改建议；没有矛盾会明确告知。有进度浮层、可取消、失败自动重试。
   - **键盘快捷键**（写作台内）：`Ctrl+Enter` 生成本章 · `Ctrl+Shift+Enter` 续写 · `Ctrl+S` 保存 · `←/→` 切换章节（焦点在编辑器内时 ←/→ 移动光标、不切章）。
   - **生成本章也走下方预览**：点「生成本章」（快捷键 `Ctrl+Enter`）不再清空编辑器——正文保持原样，生成过程在下方预览区逐段展开（实时耗时、可取消），完成后点「✓ 采用此版本」才并入正文（入生成历史），或「✕ 放弃」保持原文；取消/失败时可选用已生成的部分，失败可直接「↻ 重新生成」。
   - **全文对比（差异高亮）**：生成本章完成后，预览区可点「👁 全文对比」——宽弹窗双栏对照「当前正文 vs 生成的新稿」，按句做 LCS 差异：被删除的句子标红划线、新增的句子标绿，顶部统计「新增 N 句 · 删除 M 句 · 相同 K 句」，确认后可直接「✓ 采用此版本」。
   - **多版本生成本章**：写作台工具栏「🎲 多版本」一次生成 3 个整章候选（本地为 3 个情节组合变体；AI 按「冲突升级 / 羁绊加深 / 悬念展开」三种指令分别成稿），三张卡片在下方预览区并行展开，可滚动对比字数与开头，点「✓ 采用」替换本章正文（入生成历史）。生成中可取消——已完成的候选保留可选用，或点「关闭」放弃全部。
   - **续写入口在文章下方**：写作台底部常驻「➕ 续写本章」条（快捷键 `Ctrl+Shift+Enter` 同效）。点击后不遮罩编辑器，续写过程在下方独立工作区逐段展开（实时显示耗时，可「✕ 取消」），原文保持可见；完成后自动合并进正文并滚动到文末衔接处，取消/失败时已生成的部分也会保留。
   - **多版本续写**：同一续写入口条上的「🎲 多版本续写」一次生成 3 个不同走向的候选（本地引擎为 3 个剧情组合变体；AI 引擎按「冲突升级 / 羁绊加深 / 悬念展开」三种指令分别续写），三张卡片并行展开，可滚动预览并对比字数，点「✓ 采用」把选中的版本并入正文（入生成历史）。生成中可「✕ 取消」——已完成的候选仍保留可选用，或点「关闭」放弃全部。
   - **续写取消后可选处理**：续写生成中取消（或失败）时**不再自动合并**——已生成的部分留在工作区，由你选择：「✓ 并入正文」（合并保存）、「📝 保留为草稿」（正文不动，存为草稿刷新后可恢复）、或「✕ 丢弃」。
   - **全局主题**：顶栏 🌓 按钮一键切换深色/浅色全局主题，偏好自动持久化。
   - **专注模式**：写作台工具栏点「🧘 专注」隐藏顶栏、侧栏、灵感面板与工具栏，只留纸张居中写作；右上角浮动「✕ 退出专注」或按 `Esc` 退出。偏好持久化——开启后下次打开写作台自动进入，切到大纲/角色页会临时收起、回到写作台自动恢复。
   - **纸张质感**：写作台工具栏「📄」下拉可在六种纸张背景间一键切换——📄 纯白 / 📜 宣纸米白（默认）/ 🕯️ 暖黄 / 🧻 羊皮纸 / 🌿 墨绿 / 🌙 深色护眼（夜间写作），全部带微噪点纸纹，选择会持久化并在刷新后回显；专注模式下右上角同样有六颗圆点可随时切换（与工具栏下拉实时同步）。
   - **生成历史**：写作台工具栏点「🕘 生成历史」查看本章快照列表（每次生成本章/续写成功自动保存，最多 5 份，生成前的手写内容也会保留）。每条可「👁 对比」（当前版本 vs 快照双栏对照）或「↩ 回滚」到任一版本；大纲重新生成后历史会自动清空。快照随 JSON 备份导出/导入。
   - **全文查找**：顶部导航点「🔍 查找」（或 `Ctrl+Shift+F`）跨章节搜索人名/关键词，结果按章节分组显示命中数与上下文高亮片段；范围可切「正文 / 大纲 / 角色卡」。点「↩ 跳转」直达该章并在编辑器中标金高亮定位（输入内容后高亮自动清除），`Enter` 直达第一条结果。
   - **🔍 本地错别字检查**（写作台工具栏，无需 AI）：一键扫描当前章——「的地得」误用（后接动词→地、后接程度副词→得、人称+得/地→的，带防误报规则）与相邻重复词（单字重复 + 词组重复，内置合法叠词白名单如「慢慢/哈哈/哈哈哈」不误报）。结果按类型列出上下文与提示，每条可「👁 定位」（编辑器中标红高亮并滚动到该处）或「✓ 改为…」一键替换；全部通过时 toast 提示。规则为启发式，结果标注「疑似」供人工确认。
   - **自定义文风**：创建向导的「文风」旁点「🎨 管理」，可保存多套自定义文风（特色词汇 + 特色句式 + 替换词对）。本地引擎会把特色句式独立成段、特色词汇点缀进氛围描写；AI 深度创作时也会把词句喂进提示词。创建时在文风下拉选择、重写弹窗同样可选。
   - **📊 统计面板**：书架顶部「📊 统计」查看写作数据——总字数与章节汇总、每日写作量柱状图（可设**每日字数目标** 300/500/800/1000/2000 字，未达标柱状图变红 + 顶部提醒条，达标变绿）、连续写作天数 streak、章节字数分布直方图、年度写作日历热力图（GitHub 贡献图风格）。右上角「📤 导出报告」下载为自包含 HTML 文件，双击即可分享到社交媒体。
   - **备份与迁移**：书架每本书的卡片右上角有「⬇️」导出整本备份（`.mq.json`，含大纲、角色卡、全部章节正文、生成历史、伏笔表与元数据）；书架顶部「⬆️ 导入备份」可从备份文件恢复——换设备或重装后，导入即可继续创作。导入始终生成新书（不覆盖已有书），无效文件会被拒绝并提示原因。
   - **发布与导出**：写作台「⬇️ 导出」支持 TXT / Markdown / **EPUB 电子书**（标准 3.0 + 自动 SVG 封面，可直接导入 Kindle / Apple Books）；导出时可选**平台预设**（通用 / 起点 / 番茄 / 晋江的章节标题格式），每章可在编辑弹窗标注**发布状态**（未发布 / 起点 / 番茄 / 晋江 / 纵横 / 其他），大纲卡显示 📤 徽标。

## 🤖 配置 AI 服务商

墨泉兼容所有 **OpenAI 格式** 的接口（`/v1/chat/completions`）。在右上角「AI 设置」中填写三项：**Base URL**、**API Key**、**模型名**，然后点「测试连接」验证。

> 💡 **模型名不用记**：填好 Base URL 和 API Key 后，点模型输入框旁的「↻ 自动读取」即可拉取该服务商支持的模型列表，点击一键填入（部分平台不提供模型列表接口，此时手动输入即可）。

### DeepSeek

```text
Base URL : https://api.deepseek.com/v1
API Key  : 在 https://platform.deepseek.com 创建
模型     : deepseek-chat（推荐）或 deepseek-reasoner
```

### 智谱 GLM（BigModel）

```text
Base URL : https://open.bigmodel.cn/api/paas/v4
API Key  : 在 https://open.bigmodel.cn 创建
模型     : glm-4-flash（免费档）或 glm-4-plus
```

### 通义千问（阿里云百炼）

```text
Base URL : https://dashscope.aliyuncs.com/compatible-mode/v1
API Key  : 在 https://bailian.console.aliyun.com 创建
模型     : qwen-plus（推荐）或 qwen-turbo
```

### OpenAI / Moonshot / 其他

```text
OpenAI   : https://api.openai.com/v1           模型 gpt-4o-mini
Moonshot : https://api.moonshot.cn/v1          模型 moonshot-v1-8k
自定义   : 兼容 OpenAI 格式的任何服务，填你自己的 Base URL 与模型名
```

**生成方式三种模式（AI 设置弹窗内选择）：**

- **智能（默认）**：配置了 AI 自动用 AI，未配置用本地引擎。
- **始终用 AI**：强制 AI（未配置时自动回退本地）。
- **始终用本地引擎**：完全离线。

**失败自动重试（AI 设置弹窗内选择）：**

- **不重试**：失败立即回退本地模板。
- **重试 1 次（默认）**：网络抖动 / 解析失败时自动重试一次，正文与续写会保留已生成部分从断点续写。
- **重试 2 次**：再多一次机会（HTTP 4xx 如密钥错误不重试，直接报错）。

> 大纲与角色页顶部还有独立的「📋 本地模板 / ✨ AI 深度」切换，只影响对应模块。
> 密钥仅保存在本机浏览器，不会上传到任何服务器。

## ❓ 常见问题（FAQ）

**Q：提示「AI 请求失败（HTTP 401）」？**
API Key 错误或过期，请重新创建 Key。注意部分平台要求 Key 不带多余空格。

**Q：提示「AI 请求失败（HTTP 404）」？**
Base URL 或模型名不对。检查 Base URL 是否以 `/v1` 结尾、模型名是否与平台文档一致。

**Q：点了「测试连接」一直失败？**
先看错误信息里的 HTTP 状态：401 是 Key 错误；404 是 Base URL/端点不对；403 是无权限。若提示「CORS / 网络错误」，检查：1) 是否用了代理或防火墙拦截；2) Base URL 是否以 `https://` 开头、以 `/v1` 结尾；3) 模型名是否正确；4) 个别平台不提供 `/models` 接口——应用已自动降级用最小聊天请求验证，此时多等几秒即可。

**Q：双击打开后 AI 一直报「Failed to fetch」/ CORS 错误？**
从 `file://` 页面直接访问 API 时，浏览器会发送 `Origin: null`，部分服务商/代理会拒绝，导致即使 Key 正确也连不上。解决：① 用本地静态服务器访问（如 `python -m http.server 8080` 或 VS Code 的 Live Server 插件）；② 换支持浏览器直连的服务商（DeepSeek / 智谱 / 通义均支持）；③ 或仅用本地引擎离线创作。

**Q：我的服务商本身不支持 CORS（浏览器报 Failed to fetch，但 curl 能通）？**
这是服务商没开启跨域头，应用无法绕过浏览器安全策略。项目附带了零依赖的本地代理脚本 `proxy.js`：

```bash
node proxy.js                       # 默认转发到 https://tokenrhythm.studio/v1，端口 8787
node proxy.js https://api.deepseek.com/v1 8788   # 自定义目标与端口
node proxy.js --quiet               # 静默模式（不打印请求日志）
```

Windows 用户可直接双击 `start-proxy.bat` 启动。代理只监听本机（`127.0.0.1`），带 30 秒上游超时保护（流式生成不受影响）、浏览器中途取消时自动终止上游请求；浏览器打开 `http://localhost:8787/` 可查看运行状态页。

然后「AI 设置」里：**Base URL 填 `http://localhost:8787`**（不带 `/v1`，代理自动补），API Key 填真实 Key，模型名填真实模型名（可点「↻ 自动读取」拉取）。代理会把浏览器请求转发到目标服务并补上 CORS 响应头。

**Q：提示「模型不存在 / Model Not Found」？**
该模型名不可用（可能已下线或未开通）。换成服务商文档中推荐的新模型名，如 `deepseek-chat`、`glm-4-flash`、`qwen-plus`。

**Q：没有填 AI 配置，能用吗？**
能。所有模块都有本地引擎兜底，完全离线可用，只是风格与复杂度不及 AI 深度创作。

**Q：我的小说存在哪里？会不会丢？**
存在浏览器 localStorage 中，刷新/关闭不丢失。清空浏览器数据会删除，重要作品建议定期「导出」备份。

**Q：导出的 TXT 打开是乱码？**
导出文件为 UTF-8 带 BOM 编码，绝大多数编辑器正常。如个别老旧记事本乱码，可用 Markdown 格式导出或换用现代编辑器（VS Code / 记事本新版本）。

**Q：AI 生成中断 / 网络超时？**
检查网络与 API 额度。可在「AI 设置」中配置失败自动重试（不重试 / 1 次 / 2 次，默认 1 次）。重试时会保留已生成的部分文本从断点续写（正文 / 续写 / 大纲 / 角色均适用）；彻底失败时才回退本地模板，正文部分内容会作为草稿保留。批量生成中断不会清空已生成的章节。

**Q：生成太慢，想中途停掉？**
生成过程中进度浮层（或写作台遮罩）上有「✕ 取消」按钮，点击后立即中断 AI 请求（AbortController），已生成的部分文本会保留为草稿，大纲 / 角色保持原样不会回退为本地模板，也不会弹出「生成失败」。重试等待期间同样可以取消。

**Q：AI 返回的大纲/角色格式不对？**
部分模型偶尔不按 JSON 输出。墨泉会自动尝试解析，失败时给出提示并回退到本地模板，不影响使用。

## 🧰 技术说明

- 纯原生 JavaScript（IIFE 模块 + `window.MQ` 命名空间），无任何第三方依赖，无构建步骤。
- 文件结构：

```
index.html            入口页面（215 行）
css/style.css         墨金主题 · 6 种纸张质感 · 深浅双主题（1,204 行）
js/utils.js           工具层：种子随机 / 文本 / DOM / 错别字检查（245 行）
js/store.js           持久化层：localStorage + 内存降级（172 行）
js/content.js         内容池：11 题材库 / 名字 / 场景 / 灵感卡片（584 行）
js/prose.js           文风预设 + 段落生产器 + 性格台词（800 行）
js/engine.js          本地引擎：设定 / 角色 / 大纲 / 正文 / 续写 / 伏笔（832 行）
js/ai.js              AI 层：OpenAI 兼容 / 流式 / 重试 / 审稿 / 一致性（783 行）
js/app.js             主逻辑：视图 / 弹窗 / 交互 / 灵感续写（4,626 行）
sw.js                 Service Worker：网络优先 + 缓存回退（46 行）
manifest.json         PWA 清单（18 行）
proxy.js              本地 CORS 代理（155 行）
tests/run.js          单元回归测试（84 项）
tests/smoke.js        全流程冒烟测试（10 项）
tests/e2e.spec.js     Playwright 端到端测试（2 项）
tests/check.js        跨平台语法检查器
tests/server.js       e2e 测试静态服务器
TEST_COVERAGE.md      测试覆盖率报告
CHANGELOG.md          变更日志
RELEASE.md            发布说明
```

- 本地引擎使用种子随机数，保证同一设定多次生成结果稳定。
- AI 使用 `chat/completions` 接口，正文走流式（SSE）输出，大纲 / 角色 / 重写走非流式 JSON 解析。
- 连接检测优先 `GET /models`，部分平台不支持时自动降级为最小 `chat/completions` 请求；模型列表可通过「↻ 自动读取」一键拉取。

### 🧪 测试

一键脚本（`package.json` 的 npm scripts）：

| 命令 | 作用 |
|---|---|
| `npm run check` | 语法检查：对全部 JS 文件做 `node --check`，跨平台、秒级出结果 |
| `npm test` | 单元回归 + 全流程冒烟（Node 直接运行，无需浏览器） |
| `npm run smoke` | 仅全流程冒烟 |
| `npm run test:unit` | 仅单元回归 |
| `npm run test:e2e` | Playwright 浏览器端到端（首次需 `npm install` + `npx playwright install chromium`） |
| `npm run test:all` | 语法 + 单元 + 冒烟 + 端到端 全套 |

- **单元回归 84 项 + 冒烟 10 项**：零依赖、Node 直接运行（无需浏览器）。
- **端到端 2 项（Playwright）**：驱动真实浏览器跑 UI，覆盖 Node 测不到的交互层——创建向导 → 大纲/角色/关系图渲染 → 打字机生成本章 → 采用 → 续写 → 错别字定位修复 → 书架持久化 → 统计面板，以及关系图的点选高亮与快速建关系。首次运行需 `npm install` 并 `npx playwright install chromium` 下载浏览器（仅开发依赖，运行时仍是纯前端零依赖）。
- 覆盖边界：章节数钳制（5–9999）、越界索引、空文本、非法文风回退、多版本互异、四模板大纲、自定义地点池、伏笔重排位移、错别字白名单、JSON 解析容错等。
- 压力测试：10 题材 × 6 文风 × 3 篇幅 = 180 组合全部生成无失败。
